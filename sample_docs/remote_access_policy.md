# Remote Access Policy

## 1. Purpose
Defines requirements for accessing company systems remotely.

## 2. Authentication Requirements
- MFA is required for all remote access
- Password-only authentication is not permitted

## 3. Device Requirements
- Only company-managed devices may be used
- Devices must:
  - Have disk encryption enabled
  - Be patched regularly

## 4. Network Requirements
- VPN must be used for all remote access
- Split tunneling is prohibited

## 5. Exceptions
- Temporary exceptions may be granted for:
  - Emergency access
  - Third-party vendors
- All exceptions must:
  - Be time-limited
  - Be logged and approved
